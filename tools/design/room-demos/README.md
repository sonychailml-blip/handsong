# Handsong — демо и концепции

Копии страниц, которые Claude сделал в чате-стратегии с 11 октября по 2 ноября 2026 года.
Открываются двойным щелчком в Chrome. Нужен интернет: графика (Three.js) и шрифты грузятся из сети.

## Комнаты для Night (эскизы)

- rooms/2026-10-15_komnaty-sveta.html — «Комнаты света»: 3D-залы «Монастырь» и «Ночной лес», рука — огонь, который уходит вглубь зала.
- rooms/2026-10-16_pesnya-v-temnote.html — «Песня в темноте»: звуковой мир без света. Найти по звуку трёх поющих существ и повторить их песни. Слушать в наушниках.
- rooms/2026-10-20_zhivoy-les.html — «Живой лес»: рука — огонёк, нажатие — нота, удержание — расцветает цветок. Настроения «Сияние», «Сумерки», «Туман».
- rooms/2026-10-20_tikhie-komnaty.html — «Тихие комнаты»: «Озеро», «Сияние», «Море», «Окно».
- rooms/2026-10-31_kosmos.html — «Космос»: рука — чёрная дыра, вокруг пыль, звёзды и кометы. На экране видны звук и сила эффектов.
